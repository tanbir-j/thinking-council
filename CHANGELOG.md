# Changelog

Version numbers jump from 0.1.0 to 5.0.0 so that the public release carries the same number as the working version it was built from.

## 5.0.0 (2026-11-27)

Added

- Close Read: paragraph-level review with a diagnostic, a targeted rewrite on request, and a reconcile step for the author's own rewrite
- Meaning gate inside Full Council and Final Gate, run before any style check
- `scripts/integrity_check.py` for comparing an original with a revision
- Open Field: free thinking before any chamber convenes, with every angle adopted, adapted, or killed
- Practitioner bench: strategy partner, audit partner, private equity operating partner, and the executive in the room
- Sun Tzu on the philosophical bench for execution: terrain, timing, and sequence
- New modes: Single counsel, Boardroom Rehearsal, Drafting Room
- Executive credibility check for work that senior executives will read
- Profiles for consultancy deliverables, consulting reports, and financial and analytical models
- Venue profiles with word budgets; a venue's own brief takes precedence over them
- Scoring anchors for each dimension, a score ledger for revision reviews, a mandatory strongest objection, and a recusal rule
- Author profile template with a private override that stays out of version control
- Eleven behaviour cases and a set of trigger tests, all built from invented material
- Apache 2.0 licence

Changed

- The Council now runs on demand: only when named, or when one of its modes is named
- Scope widened from articles to professional work in general
- Publication Tribunal renamed Final Gate, with a publication variant and a client variant; the old name still works
- Only four elements are mandatory in a review: verdict, findings, strongest objection, next move
- Word budgets are accounted net across the finished piece
- The style integrity check runs at every publication Final Gate
- Drafting Room checks its own reasoning before its own style

Removed

- The author positioning charter, replaced by the profile template

## 0.1.0 (2026-07-22)
