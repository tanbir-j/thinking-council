Close read these three paragraphs together. They run consecutively in a report for an operations director.

Stock counts are done quarterly. This means errors sit for up to three months. Finance should move to monthly counts.

Supplier prices are updated annually. This means the standard cost drifts from reality. Finance should move to quarterly updates.

Overhead rates are set at budget time. This means volume changes distort product margin. Finance should review the rates each quarter.
